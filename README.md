# APOLO Synthetic Encrypted-Download Trial

This repository is a synthetic-only verification repository for evaluating public encrypted-download distribution patterns.
- Data payload: Purely invented synthetic data (contains NO private release inputs).
- Encryption format: age (RFC/FiloSottile spec) passphrase encryption (`age-encryption.org/v1`).
- Purpose: Verify anonymous fetching, ciphertext integrity, and passphrase decryption without exposing credentials.
